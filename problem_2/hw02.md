Task: Write a Python program that keeps track of some inventory items at the Holy Cross
College Store.
1. Ask the user for the price and quantity of the following items
    a. Sweatshirts
    b. T-shirts
    c. Sweatpants
    d. Mugs
2. Input validation:
    a. Validate the inputs to ensure that the price and quantity are not negative.
    b. Use input validation to warn the user if the total number of items they have (total of all 4 items) is above the warehouse capacity, which is 5,000 items.
    c. Alert the user if they need to restock any items, which they would need to do if they have less than 5 of an item.
3. Calculate the inventory of each item in monetary terms using a function (total assets,
which is the total dollar amount of sweatshirts, of T-shirts, etc.)
4. Find the monetary sum of all these items (the total inventory of all assets)
5. Output all of this information in the format of a table that is easy for the reader to read and organize their inventory.
    a. Bonus: add a blank line before and after the table to make it easier to distinguish in the console!
