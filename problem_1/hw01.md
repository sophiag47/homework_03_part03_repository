Question Prompt:
You are a farmer planting a new crop. You have an empty rectangular field to plant this crop that
is 90 ft long and 75 ft wide. Rows of this crop need to be 2 ft wide and 2 ft apart from each other,
so you need to account for 4ft total for each row. Within the rows, each seed needs to be planted
1.5 ft away from each other in order to give the plants enough room to establish their roots. All
of the rows must be parallel.

Write a Python script that answers the following problems to help you plan your field of crop:

1. How should you configure your rows if you want to maximize the number of seeds you
can plant? Will you be able to plant more seeds if you make the rows parallel to the width
or parallel to the length? (Remember you can’t have part of a row! Only full rows!)

2. With the configuration in your answer to question 1, how many seeds will you be able to
plant? Print this number with a label in front of the number saying “Total seeds planted:
[INSERT NUMBER]”.

3. You need to order seed packets for this crop. The seed packets come with 15 seeds per
packet. Answer the following questions in your same Python script, and for each
question, print the number in addition to a label that tells you what the number means.
(For example, if the answer to question 3a is 37, print a label like “Total packets emptied:
37”.)
    a. How many packets will you use and empty? (Hint: there are a couple of ways to find this, but the math module can be useful for this)
    b. How many packets will you need in total? (Hint: the math module can be useful for this)
    c. How many seeds will be left over at the end of planting?

4. In the python script, print an order for the seed packets to send to the supplier that follows
the following format:

Order: [INSERT ANSWER TO QUESTION 3b HERE] seed packets
Deliver to:
Purple Farm
100 Mountain Tree Ln.
Farmville, MA 00000

5. BONUS: Represent the total number of seeds you will plant in binary.
